# NOVA Calculator — ماشین‌حساب نوا

## ساخت با گوشی و GitHub
۱. یک مخزن جدید با نام nova-calculator بسازید.
۲. فایل index.html را در ریشهٔ مخزن آپلود کنید.
۳. فایل .github/workflows/build-apk.yml را ایجاد و محتوای YAML همراه را در آن قرار دهید.
۴. در Actions، گزینهٔ Build NOVA APK را باز کنید و Run workflow بزنید.
۵. پس از سبز شدن اجرا، از Artifacts فایل NOVA-Calculator-APK را دانلود و از ZIP خارج کنید.
۶. APK داخل آن قابل نصب آزمایشی است. در صورت نیاز اجازهٔ نصب از این منبع را بدهید.

نسخهٔ فعلی debug و برای تست است، نه انتشار در مارکت. کلید debug در اجراهای جداگانه ممکن است عوض شود؛ در این حالت نصب آپدیت روی نسخهٔ قبلی ممکن نیست و حذف نسخهٔ قبلی تاریخچه و حافظه را پاک می‌کند. برای انتشار و آپدیت پایدار باید کلید امضای شخصی ثابت تنظیم شود. هیچ کلید یا رمزی را در مخزن قرار ندهید.

برنامه مجوز اینترنت ندارد. همهٔ محتوا داخل APK است. تاریخچه و حافظه با DOM Storage در WebView ذخیره می‌شوند. Android System WebView گوشی باید به‌روز باشد.

برای تغییر ظاهر یا محاسبات، index.html را عوض کنید و دوباره APK بسازید. فایل‌های پروژهٔ Android در هر اجرا توسط workflow ایجاد می‌شوند؛ تنظیمات آن‌ها را در بخش Prepare offline Android project تغییر دهید.
